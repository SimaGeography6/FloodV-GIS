# GIS-Based Flood Vulnerability Assessment System

React + Vite dashboard based on the supplied flood-vulnerability dashboard source.

## Local setup

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

1. Create a GitHub repository named `flood-vulnerability-dashboard`.
2. Push this project to the `main` branch.
3. Open **Settings → Pages**.
4. Select **GitHub Actions** as the source.
5. The included workflow deploys the `dist` folder automatically.

## Git commands

```bash
git init
git add .
git commit -m "Initial flood vulnerability dashboard"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/flood-vulnerability-dashboard.git
git push -u origin main
```
